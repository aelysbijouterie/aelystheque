Vidéos

Présentation / tutos : 3 minutes maximum chacune. Elles s’ouvrent dans une fenêtre sur la page d’accueil, sous l’outil.
Pour un démarrage instantané : MP4 H.264 en 720p, « optimisé web ». ffmpeg -i entree.mp4 -vf scale=-2:720 -c:v libx264 -crf 24 -c:a aac -movflags +faststart sortie.mp4 (ou HandBrake, preset « Fast 720p30 », case « Optimisé pour le web »). Résultat : environ 15 à 25 Mo pour 3 min.
